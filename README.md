# Churn Prediction with Keras

Neural network model to predict customer churn using TensorFlow/Keras.

## Setup

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python churn.py
```

Place `Churn_Modelling.csv` in the project root (included in this repo).
